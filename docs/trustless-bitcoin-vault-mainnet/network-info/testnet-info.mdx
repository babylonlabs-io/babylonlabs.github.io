## Try it first on Testnet

Mainnet involves real BTC and real value. If you want to rehearse the full TBV flow — peg-in, activation, borrowing, redemption — with **no real value at risk**, run it first on the public **Testnet**.

Testnet runs on:

- **Bitcoin Signet** for the Bitcoin side
- **Ethereum Sepolia** for the Ethereum side
- a **faucet** for free test coins, so you never spend real funds

The steps mirror mainnet, so a testnet run is a faithful dry run before you transact for real. When you are ready, come back to **Setup (Mainnet)** and confirm you are allow-listed.

For the testnet walkthrough, wallets, faucet, and addresses, see the **TBV Testnet documentation**.
