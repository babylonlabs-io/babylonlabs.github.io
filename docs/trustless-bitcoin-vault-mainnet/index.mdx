**Trustless Bitcoin Vault (TBV)** lets Bitcoin holders use native BTC as collateral in DeFi — **without bridges, wrapping, or trusting a custodian.** The BTC stays on the Bitcoin Network in a Taproot script the depositor co-signs; an Ethereum-side protocol tracks each vault and lets an integrated application use it as collateral. **Aave v4 borrowing is the first application built on TBV.**

> **Beta Mainnet.** TBV is launching on mainnet in a **capped, allowlisted beta** — real BTC and real value, conservative limits, rolled out in phases. If you'd like to rehearse the flow first with no real value, use the **Testnet** section.

## What you can do with TBV

TBV is a **primitive**, not a single product: it turns native BTC into programmable collateral that many DeFi applications can consume. Aave v4 lending is live; other applications (Morpho Blue, stablecoins, perpetual DEXs, cross-chain markets) are on the roadmap. See **Use cases**.

- **Borrowers** — lock BTC, borrow assets on Aave v4, keep custody of your Bitcoin.
- **Builders** — integrate a new application on the vault layer, build on top of the Aave app, or automate with the SDK. See **Building on TBV**.
- **Operators** — Vault Provider, Vault Keeper, and Universal Challenger roles are permissioned and **invite-only during Beta**. See **Operators**.
