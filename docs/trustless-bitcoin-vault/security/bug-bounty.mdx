title: Bug bounty
---

A production bug-bounty program is being set up alongside the mainnet launch, rewarding researchers who find and responsibly report security issues in TBV.

## Status

The program launches with mainnet. Its platform, scope, severity classification, and reward tiers are **to be announced at launch**.

| Item | Detail |
|---|---|
| Program / platform | To be announced at launch |
| In scope | To be announced at launch |
| Severity classification | To be announced at launch |
| Reward tiers | To be announced at launch |
| Rules & eligibility | To be announced at launch |

## What to expect

The bounty is expected to cover the same trust surface reviewed in the audits — the on-chain contracts, the off-chain operator services, and the cryptographic protocol (pre-signed Bitcoin transaction graph, WOTS commitments, BABE, and the SP1 + Groth16 proof pipeline). Full details are published when the program goes live.

## Before the program is live

Until the bounty is published, please still report any vulnerability you find privately through the process on **Responsible disclosure**. Do not disclose issues publicly.
