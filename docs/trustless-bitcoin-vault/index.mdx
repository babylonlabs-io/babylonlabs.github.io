**Trustless Bitcoin Vault (TBV)** lets Bitcoin holders use native BTC as collateral in DeFi — **without bridges, wrapping, or trusting a custodian.** The BTC stays on the Bitcoin Network in a Taproot script the depositor co-signs; an Ethereum-side protocol tracks each BTC vault and lets an integrated application use it as collateral. **Aave v4 borrowing is the first application built on TBV.**

:::info Two networks
TBV runs a **capped, allowlisted Beta on mainnet** (real BTC and real value, rolled out in phases) and an **open public testnet** with no real value. To rehearse the flow before committing real funds, start on testnet. See [Networks](./network-info/networks.mdx) and [Beta Mainnet: what to expect](./start-here/beta-mainnet.mdx).
:::

## What you can do with TBV

TBV is a **primitive**, not a single product: it turns native BTC into programmable collateral that many DeFi applications can consume. Aave v4 lending is live; other applications (Morpho Blue, stablecoins, perpetual DEXs, cross-chain markets) are on the roadmap. See [Use cases](./start-here/use-cases.mdx).

- **Borrowers** — lock BTC, borrow assets on Aave v4, keep custody of your Bitcoin.
- **Builders** — integrate a new application on the vault layer, extend the Aave application with a resolver, or automate with the SDK. See [Building on TBV](./building-on-tbv/overview.mdx).
- **Operators** — Vault Provider, Application Vault Keeper, and Universal Challenger roles are permissioned and **invite-only during Beta**. See [Operators](./operators/overview.mdx).
